Drafts you make unasked are now draft works in {human_name}'s Library, not notes under `{agent_dir}/Prepared/`: each opens in the Library with its own chat, and they keep it or let it go. Drafts made for a task stay beside the task.

1. Run `brain install-skills`, then read the explore skill's step 5 for how a draft work is made.
2. `brain state --json` lists the open drafts under `prepared`. For each one, make the draft work as step 5 says: `--title` its title, `--what` its `what`, `--why` its `why` in the owner's words (`Toward <goal>`, `You said “…”`, `For <the day>`), `--hub` its matter's title when it has one, and a `--description` from the note. Write the note's body into the work's `index.md`, run `brain works goal <slug> --goal G-n` when the note names an active goal, and move its row with `brain reception move <its id> work:<slug>`.
3. In `{agent_dir}/Reception/`, find `draft` rows marked `used` whose note is still under `{agent_dir}/Prepared/` without `task:`. Make each a work the same way, then `demiurge works keep <slug>`, so what they used is in their Library. Leave the row as it is.
4. For each note you moved, replace every wikilink to it with the work's name in plain words ("Lisbon day plan, in the Library"), then delete the note. Leave every other note under `{agent_dir}/Prepared/` where it is.
5. If `demiurge works new` says the Library is not set up, skip steps 2 to 4: the drafts stay notes.
6. Run `brain validate`, fix what it names, then `brain compile-context --write` and `brain migrate-done`.
